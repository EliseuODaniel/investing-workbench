# Roadmap

## Phase 1
- Stabilize the repository, CI, and developer workflow.
- Prepare the repo for Codex with `AGENTS.md`, skills, and project docs.
- Introduce a service layer and logging baseline.

## Phase 2
- Build the new domain and application spine in `src/bitcoin_martingale/`.
- Migrate the backtest engine behind adapters.
- Add reproducible run manifests and richer analytics.

## Phase 3
- Expand frontend into a workspace for runs, comparisons, and reports.
- Add optimization, walk-forward testing, and richer dataset management.

## Phase 4
- Add advanced educational and research features.
- Improve explainability, benchmarking, and operational robustness.
